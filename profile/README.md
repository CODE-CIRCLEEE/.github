# Code Circle | Learn & Land

Learn together. Land your first internship.

We are a student community that learns one skill every month, builds projects together, and helps each other get paid internships.

## What we do
- Monthly skill themes (Python, SQL, web development, DSA)
- Weekly challenges and live sessions
- Resume reviews and mock interviews
- Shared internship tracker and referrals

## Weekly schedule
- Monday: new challenge
- Wednesday: live session
- Friday: project showcase
